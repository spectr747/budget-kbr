# Бюджеты органов местного самоуправления КБР

Интерактивный дашборд местных бюджетов 13 муниципальных образований Кабардино-Балкарской Республики за 2020–2025 годы (React 18 + D3.js v7, перекрёстная фильтрация).

**Открыть:** https://spectr747.github.io/budget-kbr/ (вход по логину и паролю).

## Как устроена защита

`index.html` — страница входа. Сам дашборд лежит в ней в зашифрованном виде (AES-256-GCM, ключ выводится из логина и пароля через PBKDF2-SHA-256, 600 000 итераций). Без верных логина и пароля дашборд нельзя ни открыть, ни прочитать в исходном коде. Логин и пароль в репозитории не хранятся.

## Как обновить дашборд

```bash
KBR_LOGIN='логин' KBR_PASSWORD='пароль' node tools/encrypt.mjs dashboard.html index.html
```

`dashboard.html` — открытая версия дашборда (в репозиторий не кладётся). Той же командой можно сменить пароль.

## Данные

- Суммы бюджетов **примерные** (пометка `source: "пример"`), их нужно заменить данными «Базы данных показателей муниципальных образований» Росстата.
- Границы муниципальных образований: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL.
